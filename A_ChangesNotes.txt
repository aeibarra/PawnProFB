relationship between tables

   Customer to Transactions the field is Custno
   Transactions to InventoryItems the field is TransactionNo

The table InventoryItems has a self reference field called InvOriginalItemNo. Everytime the Items change status to "For Sale" a copy of this record is created and 
a reference to the previous InvItemNo is set in InvOriginalItemNo.

For InventoryItems table field InvItemNo the new values obtain calling the function fn_GetNextKey with parameter 'InventoryItems'. That is from Database standpoint
From Delphi standpoint there is a function in the main Datamodule that does that. Is called DM.GetNextKey('InventoryItems'); return an integer of course.

Status From Pawn Can only change to 
   Original Items Status    New Items Status
     Pawn to Redeem          no new item created
     Pawn to scrap           no new item created
     Pawn to default         new item status For Sale

Everytime the Item Status is change log it in a table.

In the change status process only allow to change from Pawn to one of the status and back.

In the POS screen is where we can change the status from For Sale to Sold
